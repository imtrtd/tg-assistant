# Стереть данные: /wipe

Кнопки со стиранием под паролем. Удаление необратимо.

1. Задать пароль (один раз): `/wipe set ваш_пароль`. Сменить: `/wipe set старый новый`.
   От 6 символов, без пробелов. Сообщение с паролем бот сразу удаляет, в базе хранится
   только хеш (scrypt).
2. `/wipe` — три кнопки:
   - **🗄 Архив чатов** — сохранённые сообщения собеседников и их правки;
   - **🧨 Всё в базе** — архив, заметки, напоминания и наблюдения (пользователь и пароль остаются);
   - **💬 Сообщения в чате** — бот удаляет свои и ваши недавние сообщения в личке.
     Telegram разрешает удалять только за последние 48 часов, что не удалилось, останется.
3. После нажатия введите пароль одним сообщением (120 секунд), оно тоже удаляется.

Пять неверных паролей подряд блокируют стирание на 15 минут (счётчик в памяти процесса).
Команда работает только в личке. Потеряли пароль — задайте новый нельзя без старого:
сбросьте поле `users.wipe_password_hash` в базе (`UPDATE users SET wipe_password_hash = NULL`).
