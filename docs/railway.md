# Запуск на Railway (без своего компьютера)

Railway собирает бота из GitHub по `Dockerfile` и держит процесс включённым
постоянно. Всё делается из браузера, можно с телефона.
Новый аккаунт получает пробный кредит. Потом нужен тариф Hobby (около 5 $ в месяц),
бот укладывается в него с запасом.

## 1. Проект

1. Откройте https://railway.com и войдите через GitHub.
2. **New Project → Deploy from GitHub repo → `imtrtd/tg-assistant`**.
   Если репозитория нет в списке, нажмите **Configure GitHub App** и дайте к нему доступ.
3. Railway найдёт `railway.json` и `Dockerfile` и начнёт сборку. Первая сборка
   упадёт без токена, это нормально.

## 2. Переменные (вкладка Variables)

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `ALLOWED_USER_IDS` | ваш Telegram id (узнать: @userinfobot) |
| `RAILWAY_RUN_UID` | `0` — иначе бот не сможет писать в том |

Токен вводится только здесь, в чат его не присылайте.

## 3. Том для базы

**Settings → Volumes → Add Volume**, путь монтирования `/app/data`.
Без тома база (заметки, напоминания, архив) пропадает при каждом деплое.

## 4. Публичный адрес (мини-приложение)

**Settings → Networking → Generate Domain**. Railway сам передаст боту порт (`PORT`)
и домен (`RAILWAY_PUBLIC_DOMAIN`). Из домена бот соберёт `WEB_APP_URL` и при
старте поставит кнопку мини-приложения. Задавать `WEB_APP_URL` вручную не нужно.

## 5. Постоянный адрес и вход без ссылки из чата

Домен Railway (`https://….up.railway.app`) не меняется между перезапусками. Чтобы
заходить по нему напрямую, без одноразовой ссылки из `/web`, один раз настройте
в @BotFather:

1. **Кнопка «Войти через Telegram» в браузере:** `/setdomain` → выберите бота →
   отправьте домен Railway без `https://`. После этого на странице входа появится
   кнопка Telegram. Войти могут только id из `ALLOWED_USER_IDS`.
2. **Мини-приложение по ссылке `t.me/TG_auto_helper_bot?startapp`:** `/mybots` →
   бот → **Bot Settings → Configure Mini App → Enable Mini App** → вставьте полный
   адрес `https://….up.railway.app`. Ссылка откроет приложение из любого чата,
   а у бота в профиле появится кнопка «Открыть».

Чаты из архива (Telegram Business) хранятся в базе на томе `/app/data`,
поэтому не теряются при перезапусках и обновлениях.

## 6. Проверка

- **Deployments → View logs**: должно быть `Start polling`.
- Напишите боту `/start`.
- Пока бот работает на Railway, не запускайте его копию на ПК. С одним токеном
  Telegram отдаёт обновления только одной копии, вторая получит `Conflict`.

Обновление: каждый мерж в `main` Railway разворачивает сам.
