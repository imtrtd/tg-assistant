# Темы в чате с ботом

Если у бота в @BotFather включён режим тем, Telegram без настройки бота заводит новую
тему на каждое сообщение, отправленное вне тем. Бот наводит порядок сам: при первом
обращении создаёт постоянные темы и дальше пишет только в них.

| Тема | Что туда приходит |
|---|---|
| 🏠 Главное | меню, справка, настройки |
| 📝 Заметки | `/note`, `/notes`, `/find`, `/edit`, `/del`, `/export`, быстрое сохранение текста |
| ⏰ Напоминания | сработавшие напоминания, утренняя сводка, `/remind`, `/reminders`, `/digest` |
| 🗄 Архив | изменённые собеседниками сообщения, `/archive`, `/chats` |
| 🗑 Удалённые | удалённые собеседниками сообщения с фото и голосовыми, `/deleted` |
| 📱 Приложение | закреплённая кнопка мини-приложения |

- Команду можно написать в любой постоянной теме — ответ придёт туда же.
- Если написать вне тем (Telegram создаст новую тему), бот ответит в подходящей
  постоянной теме, а лишнюю тему удалит.
- Удалили тему по ошибке — `/topics` создаст её заново.
- Кнопка в «Приложении» обновляется сама, когда меняется адрес туннеля.

## Как включить

В @BotFather: `/mybots` → бот → **Bot Settings** → режим тем (**Threaded Mode**) → включить.
Перезапустите бота — в логе появится `Topics mode is on`.

**Важно:** там же запретите пользователям создавать темы. Пока это разрешено, Telegram
заводит новую тему на каждое сообщение вне тем (бот лишь удаляет их задним числом).
Если разрешено, бот пишет об этом предупреждение в лог при старте и в ответе на `/topics`.

Без режима тем бот работает как раньше, в одном общем чате.
