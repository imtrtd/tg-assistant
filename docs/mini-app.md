# Мини-приложение внутри Telegram

Заметки, напоминания и архив чатов открываются прямо в Telegram — кнопкой **«Открыть»**
слева от поля ввода, командой `/app` или кнопкой **«🗄 Открыть переписку»** под
уведомлением об изменённом или удалённом сообщении.

Telegram открывает мини-приложения только по **HTTPS**. Есть два способа его получить.

## Способ 1. Без домена — бесплатный туннель Cloudflare

Подходит, чтобы запустить всё у себя на компьютере или на VPS без домена. Аккаунт
Cloudflare не нужен. Адрес выдаётся случайный (`https://….trycloudflare.com`) и меняется
при перезапуске туннеля — бот сам узнаёт новый адрес и обновляет кнопку в Telegram.

### Через Docker

В `.env`:

```
WEB_APP_URL=
COMPOSE_PROFILES=tunnel
WEB_TUNNEL_METRICS_URL=http://cloudflared:2000
```

```bash
docker compose up -d --build
docker compose logs bot | grep "Mini App"   # Mini App is available at https://….trycloudflare.com
```

### Без Docker (Windows, macOS, Linux)

1. Скачайте `cloudflared`: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
2. В отдельном окне терминала:
   ```bash
   cloudflared tunnel --url http://localhost:8080 --metrics localhost:2000
   ```
3. В `.env` бота: `WEB_APP_URL=` (пусто) и `WEB_TUNNEL_METRICS_URL=http://localhost:2000`.
4. Запустите бота: `python -m tg_assistant`. В логе появится
   `Mini App is available at https://….trycloudflare.com`.

Cloudflare называет такие туннели тестовыми: без гарантий доступности. Для постоянной
работы лучше способ 2.

## Способ 2. Свой домен

На VPS с доменом HTTPS даёт Caddy — см. [deploy.md](deploy.md), раздел
«Веб-интерфейс и мини-приложение».

## Что внутри

- **Заметки** и **напоминания** — список, поиск, создание, правка, удаление.
- **Архив** (если подключён Telegram Business, см. [archive.md](archive.md)):
  - состояние подключения, счётчики и переключатели уведомлений;
  - список чатов с поиском; внутри — переписка «пузырями», как в Telegram: изменённые
    сообщения с прежними версиями, удалённые подсвечены красным; фильтр «изменённые /
    удалённые»; подгрузка более ранних сообщений;
  - фото и статичные стикеры видны прямо в переписке, остальное (голосовые, видео, файлы)
    кнопка **«Прислать в Telegram»** отправит вам в чат с ботом;
  - вкладка «Удалённые» — всё, что стёрли собеседники, с переходом к месту в переписке.
- **Настройки** (шестерёнка) — часовой пояс и утренняя сводка.

Кнопка «Назад» Telegram возвращает из переписки к списку чатов.

## Прямые ссылки

- `https://t.me/<имя_бота>?startapp=archive` — открыть сразу архив;
  `…?startapp=archive_123456` — переписку с пользователем 123456.
  Ссылка с `startapp` работает, если в @BotFather у бота настроено основное
  мини-приложение: **Bot Settings → Configure Mini App → Main App** (укажите тот же адрес).
  С туннелем адрес меняется — для постоянной ссылки нужен свой домен.
- Аналогично `startapp=notes` и `startapp=reminders`.
