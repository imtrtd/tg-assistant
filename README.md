# tg-assistant

Telegram-ассистент: бот, который помогает автоматизировать рутинные задачи прямо в мессенджере.

## Возможности

- **Заметки:** `/note текст` (или ответом на сообщение), `/notes` со списком и кнопками,
  `/find` поиск по словам и `#тегам`, `/edit`, `/del`.
- **Напоминания:** `/remind через 15 минут …`, `/remind завтра в 9 …`, `/remind 25.12 …`,
  повторы `каждый день`, `по будням`, `каждую пятницу`; `/reminders` список с удалением;
  кнопки «Готово» и «Отложить» у сработавшего напоминания; `/timezone` часовой пояс.
- **Веб-интерфейс и мини-приложение:** заметки и напоминания в одном окне — внутри Telegram
  (кнопка меню, `/app`) или в браузере (`/web` присылает одноразовую ссылку для входа).
  Светлая и тёмная темы, на широком экране — два столбца.
- В планах: AI-ассистент, интеграции.

## Быстрый старт

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Клонируйте репозиторий и установите зависимости (нужен Python 3.11+):
   ```bash
   git clone https://github.com/imtrtd/tg-assistant.git
   cd tg-assistant
   python -m venv .venv && source .venv/bin/activate
   pip install -e ".[dev]"
   ```
3. Скопируйте `.env.example` в `.env` и укажите `TELEGRAM_BOT_TOKEN`.
4. Запустите бота:
   ```bash
   python -m tg_assistant
   ```
   При запуске автоматически создаётся база `data/bot.db` и применяются миграции.
5. Напишите боту `/start`: пока `ALLOWED_USER_IDS` пуст, он ответит «доступ закрыт»
   и покажет ваш Telegram id. Впишите его в `ALLOWED_USER_IDS` в `.env` и перезапустите бота.
6. Веб-интерфейс в браузере на этом же компьютере: добавьте в `.env`
   `WEB_APP_URL=http://localhost:8080`, перезапустите бота и отправьте ему `/web`.
   Мини-приложению в Telegram нужен HTTPS — см. [docs/deploy.md](docs/deploy.md).

## Запуск на сервере

Docker и скрипты для VPS: см. [docs/deploy.md](docs/deploy.md). Локально в Docker:

```bash
docker compose up -d --build
```

## Разработка

```bash
ruff format .   # форматирование
ruff check .    # линтер
pytest          # тесты

alembic revision --autogenerate -m "описание"   # новая миграция после изменения моделей
```

Структура:

```
src/tg_assistant/
  __main__.py      # точка входа: миграции + запуск polling
  bot.py           # сборка диспетчера
  config.py        # настройки из окружения / .env
  db/              # модели SQLAlchemy, движок, работа с пользователями
  middlewares/     # доступ по белому списку, сессия БД и текущий пользователь
  reminders/       # разбор времени, планировщик отправки напоминаний
  web/             # веб-интерфейс: сервер aiohttp, JSON API, вход, static/ со страницей
  handlers/        # обработчики команд и ошибок
  migrations/      # миграции Alembic
tests/             # тесты
deploy/            # скрипты для VPS: установка, обновление, резервные копии
docs/deploy.md     # инструкция по запуску на сервере
```
