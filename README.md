# tg-assistant

Telegram-ассистент: бот, который помогает автоматизировать рутинные задачи прямо в мессенджере.

## Возможности

- **Заметки:** `/note текст` (или ответом на сообщение), `/notes` со списком и кнопками,
  `/find` поиск по словам и `#тегам`, `/edit`, `/del`.
- **Напоминания:** `/remind через 15 минут …`, `/remind завтра в 9 …`, `/remind 25.12 …`,
  повторы `каждый день`, `по будням`, `каждую пятницу`; `/reminders` список с удалением;
  кнопки «Готово» и «Отложить» у сработавшего напоминания; `/timezone` часовой пояс.
- **Быстрое сохранение:** просто напишите боту — он предложит сохранить текст в заметки или,
  если в нём есть время («завтра в 9 позвонить»), поставить напоминание. Пересланные сообщения
  сразу сохраняются заметкой с указанием автора.
- **Утренняя сводка:** `/digest 8:00` — каждый день план напоминаний на сегодня; `/digest off`.
- **Экспорт:** `/export` присылает все заметки одним .txt-файлом.
- **Оповещения об ошибках:** если задан `ADMIN_IDS`, бот присылает туда трассировку (не чаще раза в минуту).
- **Архив чатов** (через Telegram Business): бот сохраняет сообщения из ваших личных чатов и
  присылает вам, если собеседник **изменил** (было → стало) или **удалил** сообщение, вместе
  с фото, голосовыми и файлами. `/archive` — состояние и настройки, `/chats` — чаты в архиве
  с выгрузкой в .txt, `/deleted` — последние удалённые. Подключение — в [docs/archive.md](docs/archive.md).
- **Веб-интерфейс и мини-приложение:** заметки и напоминания в одном окне — внутри Telegram
  (кнопка меню, `/app`) или в браузере (`/web` присылает одноразовую ссылку для входа).
  Светлая и тёмная темы, на широком экране — два столбца. Сводка на день и настройки
  (часовой пояс, время утренней сводки) — прямо в приложении.
- **Публичный поиск:** `/search` посты в открытых каналах (даты и `in:@канал`),
  `/sources` каналы и чаты по теме, `/channel @имя` сводка публичного канала или группы,
  `/watch`, `/unwatch`, `/watches` — наблюдение за упоминаниями. Нужна отдельная
  пользовательская сессия Telethon (`API_ID`, `API_HASH`, `TELEGRAM_SESSION`).
  Телефоны, история ников, оценка даты регистрации людей и слитые базы не ищутся.
  Подробно — [docs/research.md](docs/research.md).
- В планах: AI-ассистент, интеграции.

## Команды и меню

При старте бот сам регистрирует меню команд (по-русски) и короткое описание.
В личном чате — все команды. В группах нет `/web`, `/archive`, `/chats` и `/deleted`:
это личные действия, в меню группы они только мешают. Написать их вручную по-прежнему можно.

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Приветствие и разделы |
| `/note`, `/notes`, `/find`, `/edit`, `/del` | Заметки |
| `/remind`, `/reminders`, `/timezone` | Напоминания и часовой пояс |
| `/digest` | Утренняя сводка (`/digest 8:00`, `/digest off`) |
| `/export` | Все заметки одним файлом |
| `/archive`, `/chats`, `/deleted` | Архив чатов |
| `/app`, `/web` | Мини-приложение и вход в браузере |
| `/search` | Посты в публичных каналах |
| `/sources` | Публичные каналы и чаты по теме |
| `/channel` | Сводка публичного канала или группы |
| `/watch`, `/unwatch`, `/watches` | Наблюдение за упоминаниями |

`/start` и `/help` показывают баннер и кнопки: Заметки, Напоминания, Архив чатов,
Сводка, Настройки, Мини-приложение. Внутри раздела есть «Назад».
В личке внизу ещё клавиатура: заметки, напоминания, сводка и меню.

Кнопка слева от поля ввода открывает мини-приложение, если `WEB_APP_URL` начинается
с `https://`. Иначе это обычное меню команд.

## Оформление

Картинки лежат в `src/tg_assistant/assets/`:

- `avatar.png` — 640×640, аватар бота;
- `description.png` — 640×360, картинка в пустом чате;
- `banners/` — обложки разделов, бот шлёт их в `/start` и в меню;
- `icons/` — иконка мини-приложения (она же в `web/static/`).

Аватар и картинку описания Bot API не ставит. Их один раз загружают через
[@BotFather](https://t.me/BotFather): `/setuserpic` и `/setdescriptionpic`.
Текст описания и «о боте» бот записывает сам при запуске.
Подробно — в [docs/appearance.md](docs/appearance.md).

## Быстрый старт

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Клонируйте репозиторий и установите зависимости (нужен Python 3.11+):
   ```bash
   git clone https://github.com/imtrtd/tg-assistant.git
   cd tg-assistant
   python -m venv .venv && source .venv/bin/activate
   pip install -e ".[dev]"
   ```
3. Скопируйте `.env.example` в `.env` и укажите `TELEGRAM_BOT_TOKEN`.
4. Запустите бота:
   ```bash
   python -m tg_assistant
   ```
   При запуске автоматически создаётся база `data/bot.db` и применяются миграции.
5. Напишите боту `/start`: пока `ALLOWED_USER_IDS` пуст, он ответит «доступ закрыт»
   и покажет ваш Telegram id. Впишите его в `ALLOWED_USER_IDS` в `.env` и перезапустите бота.
6. Веб-интерфейс в браузере на этом же компьютере: добавьте в `.env`
   `WEB_APP_URL=http://localhost:8080`, перезапустите бота и отправьте ему `/web`.
   Мини-приложению в Telegram нужен HTTPS — см. [docs/deploy.md](docs/deploy.md).

## Заметки из других чатов

Напишите в любом личном чате `@имя_бота текст` — бот сохранит заметку и сотрёт это
сообщение (нужен архив через Telegram Business). Ответьте `@имя_бота` на чужое
сообщение — сохранится его текст. В любом чате работает и инлайн-режим. Подробнее —
[docs/notes-from-chats.md](docs/notes-from-chats.md).

## Темы в чате с ботом

В режиме тем бот сам создаёт постоянные темы — «Главное», «Заметки», «Напоминания»,
«Архив», «Удалённые», «Приложение» — и раскладывает ответы и уведомления по ним, а не
заводит новую тему на каждую команду. Подробнее — [docs/topics.md](docs/topics.md).

## Мини-приложение в Telegram

Всё — заметки, напоминания и **архив чатов** с правками и удалениями — открывается
внутри Telegram. Нужен HTTPS: в Docker, если `WEB_APP_URL` пуст, контейнер сам
поднимает бесплатный туннель Cloudflare и ставит кнопку «Открыть». Инструкция —
[docs/mini-app.md](docs/mini-app.md).

## Запуск на сервере

Бесплатная постоянно включённая машина под бота и проверку упоминаний —
[docs/oracle.md](docs/oracle.md) (Oracle Cloud Always Free, ВМ AMD). Railway из браузера:

Два экземпляра (ПК + облако) на общей базе Postgres, чтобы бот работал при выключенном

```bash
docker compose up -d --build
```

## Публичный поиск на бесплатной машине

Пошаговый запуск на Oracle Cloud Always Free (ВМ не засыпает, в отличие от Render,
Koyeb и Hugging Face Spaces) — в [docs/oracle.md](docs/oracle.md). Команды поиска —
в [docs/research.md](docs/research.md).

Секреты, которые нужно задать в `.env` на сервере (значения придумываете и храните только вы):

| Переменная | Зачем |
|---|---|
| `TELEGRAM_BOT_TOKEN` (синоним `BOT_TOKEN`) | Токен @BotFather |
| `API_ID`, `API_HASH` | Приложение с https://my.telegram.org |
| `TELEGRAM_SESSION` (синоним `SESSION_STRING`) | Строка сессии Telethon, не файл |
| `ALLOWED_USER_IDS` | Кто может писать боту |
| `DATABASE_URL` | Необязательно. Пусто или SQLite на диске ВМ; для эфемерного диска — `postgresql+asyncpg://…` (например Neon) |

Строку сессии получают локально: `python -m tg_assistant.research.login`.

## Разработка

```bash
ruff format .   # форматирование
ruff check .    # линтер
pytest          # тесты

alembic revision --autogenerate -m "описание"   # новая миграция после изменения моделей
```

Структура:

```
src/tg_assistant/
  __main__.py      # точка входа: миграции + запуск polling
  bot.py           # сборка диспетчера
  branding.py      # меню команд, описание бота, кнопка меню
  texts.py         # тексты ответов
  assets/          # аватар, картинка описания, баннеры, иконки
  config.py        # настройки из окружения / .env
  db/              # модели SQLAlchemy, движок, работа с пользователями
  middlewares/     # доступ по белому списку, сессия БД и текущий пользователь
  reminders/       # разбор времени, планировщик отправки напоминаний
  research/        # публичный поиск: Telethon, разбор запросов, наблюдения
  web/             # веб-интерфейс: сервер aiohttp, JSON API, вход, static/ со страницей
  handlers/        # обработчики команд и ошибок
  migrations/      # миграции Alembic
tests/             # тесты
deploy/            # скрипты для VPS: установка, обновление, резервные копии
docs/deploy.md     # инструкция по запуску на сервере
```
