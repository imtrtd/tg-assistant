Архив чатов

Архив чатов
  1. В @BotFather: Bot Settings → Business Mode → Turn on
  2. В Telegram: Настройки → Telegram Business → Чат-боты
  3. Выберите этого бота и чаты (нужен Telegram Premium)

Вход через Telegram

  1. Откройте чат с ботом в Telegram
  2. Отправьте команду /web
  3. Перейдите по ссылке из ответа
