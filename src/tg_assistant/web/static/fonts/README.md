# Шрифты

Из дизайн-системы imtrtd, подмножества latin и cyrillic (woff2, variable):

- Arimo — Steve Matteson, SIL Open Font License 1.1
- Geist Mono — Vercel, SIL Open Font License 1.1
- Space Grotesk — Florian Karsten, SIL Open Font License 1.1 (только латиница)

Отдаются самим ботом из `/static/fonts/` — внешних запросов нет, CSP не меняется.
